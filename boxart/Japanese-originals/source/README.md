# Japanese retail front covers

Reference scans of the Japanese Game Boy Advance retail fronts for Densetsu no Stafy 1, 2, and 3. Each file is the front face only. These are not full unfolded boxes, spines, backs, or layered box templates.

They are community-hosted references for box art, not official masters and not patch or ROM files. The bytes are the files as published at the image URLs below. Nothing here was resized, upscaled, or reencoded.

Original artwork is (c) Nintendo / TOSE. Those rights stay with Nintendo and TOSE. LaunchBox Games Database and MobyGames are the source hosts. This repository does not claim a license over these scans. They are not covered by the sharing note for the text and patches elsewhere in this repo.

English fan-edited covers stay in `boxart/` and are unchanged.
