# ComicGamerDragon box art

US-style GBA covers and Slot cfw cart labels shared publicly by u/ComicGamerDragon on r/thelegendarystarfy. This is an alternate set. The English covers at the top of `boxart/` are by omega_mog/taserak. Choose whichever set you like.

Original artwork is (c) Nintendo / TOSE.

u/ComicGamerDragon posted these as US-style covers he sourced from the LaunchBox Games Database, in [GBA Starfy Covers & Labels for Launchers & Frontends](https://www.reddit.com/r/thelegendarystarfy/comments/1xqnr9j/gba_starfy_covers_labels_for_launchers_frontends/) on November 7, 2026.

## Slot cart labels

The labels in `slot-cart-labels/` were cropped and made by u/ComicGamerDragon for Slot's Cart Studio. They are the versions he redid so they work in Slot, posted in [Starfy Cart Labels for Slot cfw](https://www.reddit.com/r/thelegendarystarfy/comments/1xrhhmn/starfy_cart_labels_for_slot_cfw/) on November 8, 2026.

An earlier set of labels was in the November 7 post. He later noted those may not work in Slot. Those first labels are the same designs with only crop and export differences, so this folder keeps only the Slot-ready versions.

- `slot-cart-labels/starfy-3-gba-slot-cart-label.png` — Starfy 3
